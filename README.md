# ScreenSound — exercícios de orientação a objetos

Projeto de console em C# com alvo .NET 8, definido em `ScreenSoundOrientadoAObj/ScreenSoundOrientadoAObj.csproj`. O projeto reúne modelos de banda, álbum e música, exercícios práticos e um desafio de podcast.

## Entrada atual

Em `ScreenSoundOrientadoAObj/Program.cs`, os exemplos musicais estão comentados. O trecho ativo cria um podcast, três episódios e convidados de exemplo, adiciona os episódios e solicita a exibição dos detalhes. Os nomes usados são dados de demonstração, sem afirmar entrevistas ou participações reais.

A pasta `Desafios Práticos` contém exercícios separados sobre alunos, contas, estoque, restaurante e outros modelos. A presença dessas classes não significa aplicações completas nesses domínios.

## Ambiente

Com SDK compatível com .NET 8, a entrada declarada pode ser selecionada por:

```sh
dotnet run --project ScreenSoundOrientadoAObj/ScreenSoundOrientadoAObj.csproj
```
